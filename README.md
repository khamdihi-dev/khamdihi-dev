### About

I'm a freelance software developer working with clients from Indonesia and abroad. I focus on delivering reliable, well-tested work on time — clear communication, dependable results, and fast turnaround.

My background is in **CLI tools and automation with Python**, which was my main focus last year. These days I mostly build **web applications and web-based tools**, while still taking on CLI and automation work when it fits the project.

**What I do**

- Web applications — frontend and backend
- Web-based tools and internal dashboards
- CLI tools and automation scripts (Python)
- Working directly with clients, from brief to delivery

**How I work**

- Clear scope and honest timelines before starting
- Consistent communication throughout the project
- Clean, maintainable code — not just something that runs
- Fast delivery without cutting corners
